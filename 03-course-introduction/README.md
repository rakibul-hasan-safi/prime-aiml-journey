## Key takeaways

**Why Python for AI/ML**
1. Easy and intuitive syntax
2. Huge ecosystem of libraries (NumPy, Pandas, scikit-learn, TensorFlow, PyTorch)
3. Platform independent
4. Integrates with C/C++, so heavy math runs fast underneath
5. Great for rapid prototyping

**Tools**

| Tool | Use it for |
|------|------------|
| VS Code | Writing scripts and full projects |
| Anaconda | Python plus data-science libraries in one install |
| Jupyter | Exploring data and testing ideas cell by cell |

> Rule of thumb: explore in Jupyter, build in VS Code.

**Mac setup notes**
- Use `python3` and `pip3`, not `python` and `pip`
- Check the install: `python3 --version`
- Run a file: `python3 hello.py`
- In VS Code: Cmd + Shift + P → *Python: Select Interpreter*
